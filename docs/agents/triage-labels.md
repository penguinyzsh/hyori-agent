# Triage Labels（分拣标签映射）

各工程技能通过五类标准分拣角色进行协作。本文件将标准角色映射为本仓库 Issue Tracker 中实际使用的标签名称。

| mattpocock/skills 标准角色 | 本仓库实际标签    | 含义说明                               |
| -------------------------- | ----------------- | -------------------------------------- |
| `needs-triage`             | `needs-triage`    | 需要维护者评估与分拣                   |
| `needs-info`               | `needs-info`      | 等待提出者补充更多信息                 |
| `ready-for-agent`          | `ready-for-agent` | 规格已明确，可交由后台 Agent 独立执行  |
| `ready-for-human`          | `ready-for-human` | 需要人工介入实现或决策                 |
| `wontfix`                  | `wontfix`         | 不予处理                               |

当技能提及某分拣角色（例如“打上可交由 Agent 执行的标签”）时，使用上表“本仓库实际标签”列对应的字符串。

如需改用其他标签命名，直接编辑上表“本仓库实际标签”列即可。
